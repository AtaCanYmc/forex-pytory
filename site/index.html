Command Line Interface (forex-scraper)

The forex-scraper executable provides instant terminal queries with zero code. It supports both Rich ANSI table rendering and clean JSON output for UNIX piping.

Flag Type Allowed Values Default Description
--source String forex, crypto, energy, metals forex Financial market calendar portal to query.
--date String YYYY-MM-DD Today Specific calendar date to fetch.
--format String table, json json Output visual formatting style.
-h, --help Flag — — Print CLI help and argument descriptions.

UNIX Pipe & jq Recipe

Extract only high-impact cryptocurrency events and format as a compact list:

Shell Script 
forex-scraper --source crypto --format json | jq '.[] | select(.impact == "high") | "\(.time) [\(.currency)] \(.event) - Actual: \(.actual)"'

Python SDK Integration

Import scrapers directly into algorithmic trading routines, quantitative analysis notebooks, or automated alert bots.

Python (3.11+) 
from datetime import datetime
import pandas as pd
from forex_pytory.core.scraper import forex_factory_scraper

# 1. Generate target URL for a specific date
now = datetime.now()
url = forex_factory_scraper.get_url(day=now.day, month=now.month, year=now.year)

# 2. Extract and validate calendar events
events = forex_factory_scraper.get_records(url)

# 3. Convert directly to Pandas DataFrame
df = pd.DataFrame([e.model_dump(by_alias=True) for e in events])
print(df[["Time", "Currency", "Event", "Impact", "Forecast", "Actual"]])

EconomicEvent Pydantic v2 Schema

All scrapers return strongly-typed instances of EconomicEvent:

Pydantic Model 
class EconomicEvent(BaseModel):
    id: Optional[str] = Field(default=None, alias="ID")
    time: Optional[str] = Field(default=None, alias="Time")
    currency: Optional[str] = Field(default=None, alias="Currency")
    event: Optional[str] = Field(default=None, alias="Event")
    forecast: Optional[str] = Field(default=None, alias="Forecast")
    actual: Optional[str] = Field(default=None, alias="Actual")
    previous: Optional[str] = Field(default=None, alias="Previous")
    impact: Optional[str] = Field(default=None, alias="Impact")

Model Context Protocol (MCP) Setup

Integrate live calendar querying directly into AI coding agents and desktop assistants like Claude Desktop and Cursor. The server exposes a standard stdio JSON-RPC interface.

1. Claude Desktop Configuration

Add to claude_desktop_config.json:

JSON 
{
  "mcpServers": {
    "forex-pytory": {
      "command": "uvx",
      "args": ["--from", "forex-pytory", "forex-mcp"]
    }
  }
}

2. Exposed Tool Signature: fetch_economic_events

Argument Type Required Description
source String Yes Market calendar to query: forex, crypto, energy, or metals.
date String No Specific date in YYYY-MM-DD format. Defaults to current date if omitted.

Architecture & Engineering Decisions

Designed according to strict anti-slop, minimal overhead, and maximum resilience principles:

  • Zero Headless Overhead: Uses cloudscraper to resolve Cloudflare v1 JavaScript challenges rather than spinning up memory-heavy Chromium or Puppeteer processes.
  • Strict URL Scheme Verification: Validates HTTPS transport schemes before firing requests, neutralizing SSRF vulnerabilities and protocol manipulation risks.
  • Deterministic Semver & Release Please: Version numbers across the Python library, MCP server, Homebrew formula, and issue templates stay dynamically synchronized.
  • Zero Frontend Dependencies: This documentation site is built with pure semantic HTML5, modern CSS custom properties, and vanilla JS. No node_modules, no webpack builds, instant 0ms load time.
