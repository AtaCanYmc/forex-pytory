# Security Policy

## Supported Versions

Only the latest release series receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in `forex-pytory`, please do not report it through public GitHub issues or discussions.

Instead, please report vulnerabilities via one of the following private channels:

1. **GitHub Security Advisory**: Submit a private report through the [Security tab](https://github.com/AtaCanYmc/forex-pytory/security/advisories/new).
2. **Direct Maintainer Email**: Contact Atacan directly at `atacanymc@gmail.com` with the subject line `[SECURITY] forex-pytory Vulnerability Report`.

### Required Information

When submitting a report, please include:
- A description of the vulnerability and affected components (CLI, SDK, or MCP server).
- Step-by-step reproduction instructions or a minimal proof of concept.
- Expected impact and potential exploitation vectors.

### Response SLA

- **Initial Response**: Within 48 hours of receipt.
- **Triage & Status Update**: Within 5 business days.
- **Fix Timeline**: Critical vulnerabilities are addressed within 14 business days, followed by a coordinated patch release and disclosure announcement.
